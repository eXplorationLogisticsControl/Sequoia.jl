API reference

Sequoia.Sequoia — Module
Sequoia

Small, generic branch and bound for mixed-integer convex problems (MISDP, MISOCP, MILP, ...). Each node solves a continuous relaxation with a convex solver of the user's choice.

There are two entry points:

  • solve(relax, lb, ub; ...): the core. You supply a node oracle relax(lb, ub) -> NodeResult that solves the relaxation with the integer variables restricted to the box [lb, ub]. You may rebuild or simplify the model at every node (e.g. eliminate blocks whose indicator is fixed to 0).
  • solve(model::JuMP.Model; optimizer, ...): convenience wrapper for a JuMP model with Bin/Int variables. It relaxes a copy of the model and changes variable bounds at every node.
  • read_dat_s reads a sparse SDPA file into an SDPAProblem, and jump_model turns that into a JuMP model solve can branch on.

The core works in the minimization sense, and the oracle's bound must be a valid lower bound on the node relaxation (a dual objective value is the safe choice).

Solving

Sequoia.solve — Method
solve(relax, lb, ub; options=Options(), incumbent=Inf, x_incumbent=nothing,
      heuristic=nothing, polish=nothing, branch=most_fractional, log_sign=1) -> Result

Branch and bound over integer variables x ∈ [lb, ub] ∩ ℤⁿ (minimization). Bounds are rounded inward to integers, and may be infinite.

Arguments

  • relax(lb, ub) -> NodeResult: the node oracle. It solves the continuous relaxation with the integer variables restricted to the box [lb, ub]. See NodeResult.
  • incumbent, x_incumbent: optional warm start (objective value and integer point). incumbent = Inf means none, and x_incumbent is then ignored. -Inf is an error.
  • heuristic(x, lb, ub) -> (value, xint) or nothing: called on every node taken from the queue that has a relaxed solution x. It looks for a feasible integer point; value must be its exact objective value.
  • polish(xint) -> value, Inf, or nothing: exact objective at an integer point, e.g. a re-solve with the integers fixed. If given, it scores relaxations that are integral only within int_tol, instead of trusting the relaxed value. Inf means the point is infeasible and nothing undecided. Either way, a node that is not fully fixed is branched further. A fully fixed node is closed on Inf and left unresolved on nothing (status :incomplete).
  • branch(x, lb, ub, int_tol) -> index or nothing: branching rule (see most_fractional). If it returns nothing for a node that still has free variables, first_free is used.
  • log_sign = 1: multiplies the incumbent and the bound in the progress log and the termination summary; the search always minimizes.

All callbacks receive copies of Sequoia's vectors, so they may modify or keep them.

See Options for limits and tolerances and Result for the output.

Sequoia.solve — Method
solve(model::JuMP.Model; optimizer, kwargs...) -> Result

Branch and bound on a JuMP model with Bin/Int variables. The model itself is not modified: Sequoia relaxes a copy and solves each node with optimizer (e.g. Clarabel.Optimizer, or optimizer_with_attributes(...)). Each node's relaxation is read with jump_result.

Other keyword arguments are as in the core solve. x and the vectors passed to heuristic/polish are ordered like the integer variables in JuMP.all_variables(model). incumbent, the values returned by heuristic and polish, the progress log, the termination summary, and the objective, bound, root_bound and trace of the result are all in the model's own objective sense. An infinite incumbent (of either sign) means no warm start.

Bounds of the integer variables may be given as variable bounds, by fixing, or as x in MOI.Interval(l, u) constraints.

SOS, semicontinuous, semi-integer and indicator constraints are not supported.

Sequoia.Options — Type
Options(; kwargs...)
Options(o::Options; kwargs...)

Settings for solve. The second form copies o with some fields replaced, e.g. Options(o; time_limit=60).

Fields

  • time_limit::Float64 = Inf: wall-clock limit in seconds, checked between nodes.
  • node_limit::Int = typemax(Int): stop once this many relaxations have been solved. A branching step solves two children, so the count can exceed the limit by one.
  • rel_gap::Float64 = 1e-6, abs_gap::Float64 = 1e-8: a node with lower bound b is pruned once b ≥ inc - max(abs_gap, rel_gap * |inc|), where inc is the incumbent value. With the default values, :optimal means optimal within these tolerances.
  • int_tol::Float64 = 1e-6: a relaxed value within int_tol of an integer counts as integral.
  • integral_objective::Bool = false: declare that the objective takes integer values at every feasible point. Lower bounds are then rounded up before pruning, to ceil(b - max(int_tol, abs_gap, rel_gap·|b|)).
  • node_selection::Symbol = :best: :best (best-bound first) or :depth (depth first, last-in first-out).
  • log_every::Float64 = 5.0: seconds between progress lines. Inf silences the progress log and the termination summary.

Sequoia.Result — Type
Result

Outcome of solve.

  • status:
    • :optimal: the incumbent is optimal within rel_gap/abs_gap.
    • :infeasible: the tree was exhausted without a feasible point.
    • :time_limit, :node_limit: a limit was reached first.
    • :incomplete: the tree was exhausted, but a fully fixed node could not be resolved (its relaxation failed, or polish returned nothing) and might hold a better point than the incumbent.
  • objective, x: the incumbent value and integer point (Inf and nothing if there is none). x can be nothing while objective is finite if the warm-start incumbent was given without x_incumbent and never improved.
  • bound: a global lower bound on the optimal value. Once the search finishes it can lie below objective by up to the gap tolerance.
  • nodes: relaxations solved. unknown: relaxations that returned :unknown.
  • root_bound: the root relaxation's bound (-Inf if it failed, Inf if infeasible).
  • time: wall-clock seconds.
  • trace: (t, nodes, bound, incumbent, open) snapshots, for gap-vs-time plots.

The JuMP interface reports objective, bound, root_bound and trace in the model's own objective sense.

source
Sequoia.gap — Function
gap(r::Result) -> Float64

Relative optimality gap |objective - bound| / max(|objective|, 1e-12). Works for either objective sense. Inf if there is no incumbent.

An :optimal result satisfies |objective - bound| ≤ max(abs_gap, rel_gap·|objective|). When the objective is (near) zero, abs_gap decides, and gap can be large.

Input

Sequoia.read_dat_s — Function
read_dat_s(path::AbstractString) -> SDPAProblem
read_dat_s(io::IO) -> SDPAProblem

Read a sparse SDPA file (.dat-s). A path ending in .gz is decompressed.

Lines starting with * or " are comments. *INTEGERS*, followed by *<index> lines, names the integer variables. Header lines may carry a trailing note (28 = m), and only their leading numbers are read. Repeated entries at the same position are summed. An off-diagonal stored on one side only is mirrored. Both sides may be stored; if they disagree, an ArgumentError is thrown.

source
Sequoia.SDPAProblem — Type
SDPAProblem(c, blocks, integers)

A sparse-SDPA problem: minimize cᵀx subject to Σᵢ Fᵢ xᵢ − F₀ ≽ 0. integers holds the 1-based indices of the integer variables, in increasing order.

blocks mixes PSDBlock and DiagonalBlock. A problem may have no variables: the constraints are then constant.

source
Sequoia.jump_model — Function
jump_model(problem::SDPAProblem) -> JuMP.Model

JuMP model of problem, minimized. Variables are created in file order. Those listed in problem.integers are integer; the file gives them no bounds, so any bounds come from the diagonal blocks. solve on this model returns the integer variables in increasing index order.

source
Sequoia.PSDBlock — Type
PSDBlock(coef)

One semidefinite block. coef[1] is F₀ and coef[i+1] is Fᵢ, each an n × n symmetric matrix.

source
Sequoia.DiagonalBlock — Type
DiagonalBlock(coef)

One diagonal block, a list of linear inequalities Σᵢ Fᵢ xᵢ − F₀ ≥ 0 componentwise. coef[1] is F₀ and coef[i+1] is Fᵢ, each a vector.

Node oracles

Sequoia.NodeResult — Type
NodeResult(status, bound, value, x)
NodeResult(status)

Result of one node relaxation, returned by a node oracle (see solve).

  • status: :optimal, :infeasible, or :unknown. :unknown means the solver failed. A failed node is never pruned: it keeps its parent's bound and is branched on.
  • bound: a valid lower bound on the node relaxation, e.g. the dual objective value. Use -Inf (or NaN) if none is available; the node then inherits its parent's bound.
  • value: the primal objective of the relaxed solution. It becomes an incumbent value when x is integral and no polish function is given.
  • x: relaxed values of the integer variables, in the order of lb and ub.

The one-argument form is for :infeasible and :unknown results.

source
Sequoia.jump_result — Function
jump_result(model, xvars) -> NodeResult

Read the result of an optimized JuMP model into a NodeResult, in the minimization sense (values are negated for a Max model). Useful when writing your own node oracle.

  • solved: OPTIMAL, LOCALLY_SOLVED, ALMOST_OPTIMAL or ALMOST_LOCALLY_SOLVED with a (nearly) feasible primal point, or SLOW_PROGRESS (e.g. MOSEK stalling at its last digit) with feasible primal and dual points.
  • infeasible: INFEASIBLE, LOCALLY_INFEASIBLE, or SLOW_PROGRESS with a dual infeasibility certificate.
  • unknown: anything else, including unbounded relaxations.

The bound is the dual objective value if the solver reports a feasible dual point. Otherwise it is -Inf, and the node inherits its parent's bound. A solver configured not to return duals therefore gets no pruning by bound. x holds the values of xvars, and plain numbers in xvars are passed through.

Note

A dual objective value is a valid bound only up to the solver's feasibility tolerances. LOCALLY_SOLVED and LOCALLY_INFEASIBLE are trusted like their global counterparts, which is correct only for convex relaxations.

Branching rules

Sequoia.most_fractional — Function
most_fractional(x, lb, ub, int_tol) -> Union{Int,Nothing}

Branching rule: pick the free variable whose relaxed value is farthest from an integer (ties go to the lowest index). Returns nothing if all free variables are integral within int_tol. If x === nothing, falls back to first_free.

source
Sequoia.first_free — Function
first_free(x, lb, ub, int_tol) -> Union{Int,Nothing}

Branching rule: pick the first variable that is not fixed (lb[i] < ub[i]), whatever its relaxed value. This is the fallback when a node has no relaxed solution.

Internals

These are not part of the public API and may change without notice.

Sequoia.Node — Type
Node

An open node of the search tree. The integer variables are restricted to [lb, ub].

  • bound: a lower bound on every point in the node. It is the maximum of the node's own relaxation bound and its parent's bound.
  • x: the relaxed solution, or nothing if the relaxation failed or its integral solution was rejected. Without x, the node is branched with the first_free fallback.
source
Sequoia.Tree — Type
Tree

Mutable state of one branch-and-bound run (minimization). Users never see it: it is created and consumed by solve.

Every point of the original box lies in exactly one of these sets, and each comes with a lower bound on its points. Their minimum is the global bound:

  • open: nodes still to be processed, each with its own bound.
  • pruned: discarded subtrees. Their smallest (rounded) bound is kept, so that a gap tolerance never turns into an overstated final bound.
  • lost: fully fixed nodes that could not be resolved. Their smallest bound is kept.
  • closed subtrees whose best point is known (infeasible, or integral relaxation). These are bounded by the incumbent.
source
Sequoia.split_point — Function
split_point(xk, l, u) -> Float64

Non-integer split value v for a variable with integer bounds l < u and relaxed value xk (nothing if there is none). The children get x ≤ floor(v) and x ≥ ceil(v), so both are non-empty and both exclude xk when it is fractional. Throws an ArgumentError if |v| ≥ 2^53, where consecutive integers are no longer representable as Float64.

Sequoia.evaluate! — Function
evaluate!(t, lb, ub, parent_bound) -> Float64

Solve the relaxation of the node [lb, ub] and act on the result:

  • infeasible: close the node.
  • failed (:unknown, or a relaxed x with NaN/Inf entries): keep the node with its parent's bound, to be branched on.
  • integral: score the integer point (polish, or the relaxed value) and update the incumbent. The subtree is closed only if the node's bound then closes it. Otherwise the point was rejected or left undecided, or its score lies above the node's bound, and the rest of the subtree may hold a better point, so it stays open. A fully fixed node holds only this point, so it is closed once scored.
  • fractional: keep the node unless its bound closes it.

The oracle and the callbacks get copies, so they cannot corrupt the tree by mutating or reusing vectors. Returns the relaxation's own bound: Inf if infeasible, -Inf if failed or unavailable.

source
Sequoia.discard! — Function
discard!(t, b) -> Bool

If a node with bound b is closed, record its bound for the final global bound and return true. Otherwise return false.

source
Sequoia.improve! — Function
improve!(t, value, x) -> Bool

Make (value, round.(x)) the incumbent if value is finite and better. Then drop the open nodes that the new incumbent closes. Returns whether the incumbent changed.
